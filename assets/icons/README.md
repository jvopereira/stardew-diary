# Ícones do jogo

Sprites de Stardew Valley, de ConcernedApe, obtidos da Stardew Valley Wiki. Usados na navegação, nos títulos das coleções e no controle de importação, preservando os pixels originais.

- `stardrop.png`: https://stardewvalleywiki.com/Special:Redirect/file/Stardrop.png
- `fishing.png`: https://stardewvalleywiki.com/Special:Redirect/file/Iridium_Rod.png
- `museum.png`: https://stardewvalleywiki.com/Special:Redirect/file/Dwarf_Scroll_I.png
- `save.png`: https://stardewvalleywiki.com/Special:Redirect/file/Chest.png

A cópia local permite carregar os ícones sem depender de requisições à Wiki durante a navegação. Imagens dos cartões também são locais, em `assets/items/`.
